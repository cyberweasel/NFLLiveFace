# NFLWatchFace

Wear OS watch face that shows Chicago Bears scores.

- `app/` – complication data source service (fetches ESPN data): "Bears Score" and "Bears Game Details"
- `watchface/` – Watch Face Format face (no code). Replace `res/drawable-nodpi/bears_logo.png` with your own logo.

Install both modules on the watch, long-press the face, choose it, then set the two bottom slots to the Bears data sources.
